🖥 BuildPC - Android додаток для конфігурації ПК

BuildPC - Android-додаток для підбору, керування та конфігурації комп’ютерних компонентів. Дозволяє користувачам формувати власні збірки ПК з сумісних деталей, працюючи з серверними даними через REST API. Додаток орієнтований на ентузіастів та користувачів, які хочуть швидко зібрати конфігурацію та зберегти її у вигляді звіту.

🚀 Функціонал
- Перегляд комп’ютерних компонентів з фільтрацією за типом, брендом та ціною
- CRUD-операції над компонентами через UI
- Формування власних конфігурацій ПК
- Генерація PDF-звіту з переліком вибраних компонентів
- Взаємодія з сервером через REST API
- Асинхронна обробка мережевих запитів та помилок
🛠 Технології
- Android (Java)
- Volley - мережевий шар та HTTP-запити
- RecyclerView + Adapters + Fragments - UI-архітектура
- PdfDocument - генерація PDF-файлів
- FileProvider - робота з файлами та доступ до них
- Node.js + Express.js - серверна частина
- Sequelize ORM
- MySQL - база даних

📦 Запуск проєкту
1. Клонувати репозиторій
2. Налаштувати сервер (Node.js / Express) за адресою: http://10.0.2.2:3000
3. Відкрити Android-проєкт у Android Studio
4. Запустити на емуляторі або реальному пристрої
